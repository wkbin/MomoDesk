# Reference Photos

Put photos of the real cat here while creating the personal MomoDesk character.

Files in this folder are ignored by Git by default so private pet photos are not accidentally committed. Keep only this README in the repository.

Recommended set:

- Front face.
- Left and right side views.
- Back view.
- Three-quarter view.
- Full-body standing photo with paws and tail visible.
- Sitting pose.
- Curled-up sleeping pose.
- Close-ups of signature markings, eyes, ears, tail, and collar.
